# آریا دانلودر (Aria Downloader) 2.1.0

دانلودمنیجر فارسی و راست‌به‌چپ برای اندروید با دو موتور داخلی:

- **HTTP بومی:** دانلود فایل مستقیم با ادامهٔ دانلود (`Range` / `ETag`)، تلاش مجدد و نمایش سرعت.
- **رسانه:** اجرای واقعی `yt-dlp` داخل برنامه با Chaquopy؛ بدون سرور یا سرویس واسط.

سورس پروژه مستقیماً در همین مخزن قرار دارد؛ برای دریافت کد به فایل ZIP نیازی نیست.

## امکانات نسخهٔ 2.1.0

- رفع انتخاب فرمت برای لینک‌های **Aparat** و **Pornhub** که codec مشخص نمی‌کنند؛ این فرمت‌ها قبلاً اشتباً حذف می‌شدند.
- پشتیبانی از لینک معمولی، اشتراک‌گذاری، Embed و دامنه‌های localized/premium و تبدیل آن‌ها به لینک استاندارد.
- دانلود موازی قطعات HLS/DASH با مقدار قابل تنظیم ۱ تا ۸ اتصال (پیش‌فرض ۴)، قطعات HTTP هشت‌مگابایتی و بافر ۲۵۶ کیلوبایتی.
- بررسی سریع‌تر پلی‌لیست‌ها با استخراج Flat و سقف ۱۲۰ مورد در هر بار.
- اصلاح درصد و حجم واقعی در حین دانلود رسانه و نمایش نام فایل‌های فعال در اعلان.
- نمایش وضعیت واقعی مجوز و کانال اعلان، دکمهٔ ورود به تنظیمات سیستم و عدم تکرار بی‌پایان درخواست مجوز.
- جدا کردن اعلان ضروری Foreground Service از اعلان اختیاری «پایان/خطا».
- حذف رمز و کلید امضا از سورس؛ پیکربندی امضا فقط از `keystore.properties` محلی خوانده می‌شود.
- نسخه‌های وابستگی استخراج برای بیلد قابل تکرار پین شده‌اند: `yt-dlp 2026.10.21` و `certifi 2026.10.23`.

## سایت‌ها و لینک‌ها

علاوه بر فایل مستقیم `http/https`، موتور رسانه از سرویس‌های پشتیبانی‌شدهٔ yt-dlp استفاده می‌کند؛ از جمله:

| سرویس | لینک‌های قابل استفاده |
|---|---|
| YouTube / YouTube Music | ویدیو، Shorts و پلی‌لیست |
| Aparat | `/v/<id>` و لینک Embed/اشتراک‌گذاری |
| Pornhub | `view_video.php?viewkey=…`، `video/show` و `/embed/<id>` |
| Spotify | آهنگ، آلبوم و پلی‌لیست؛ با تطبیق متادیتا و منبع صوتی باز |
| Instagram / TikTok / X / Facebook | محتوای عمومی؛ برخی لینک‌ها به کوکی حساب خود کاربر نیاز دارند |
| Vimeo / Dailymotion / Twitch / Reddit | ویدیو و پلی‌لیست‌های پشتیبانی‌شده |
| SoundCloud / Bandcamp / Mixcloud / Audiomack | صوت و پلی‌لیست |
| Bilibili / Rumble / VK / OK.ru / Streamable | با موتور عمومی yt-dlp |
| Namasha / Filimo / Telewebion / Archive.org | بسته به نوع محتوا و محدودیت سرویس |

لینک‌های نامأنوس و بدون پسوند هم ابتدا به موتور استخراج داده می‌شوند. پشتیبانی واقعی هر صفحه به extractor آن سرویس، محدودیت جغرافیایی و وضعیت ورود بستگی دارد؛ محتوای DRM دور زده نمی‌شود.

### نکتهٔ Spotify

اسپاتیفای استریم DRM ارائه می‌کند. برنامه فایل DRM را استخراج نمی‌کند؛ نام آهنگ و خواننده را از متادیتای عمومی می‌خواند و نسخهٔ صوتی منطبق را از منبع باز جست‌وجو می‌کند. بنابراین نام خروجی و کیفیت آن به نتیجهٔ جست‌وجو بستگی دارد.

## کیفیت و سرعت

کیفیت‌های «بهترین»، 1080p، 720p، 480p، 360p و «فقط صدا» در دسترس‌اند. برای YouTube، ترک H.264 و AAC برای ادغام بدون رمزگذاری مجدد انتخاب می‌شود.

از تنظیمات می‌توانید دو مقدار را جدا کنترل کنید:

1. **تعداد دانلود همزمان:** تعداد آیتم‌های فعال در صف.
2. **اتصال موازی هر دانلود:** تعداد قطعات همزمان HLS/DASH در هر آیتم؛ برای Aparat و بسیاری از سرویس‌های ویدیویی مؤثر است.

مقادیر خیلی زیاد لزوماً سریع‌تر نیستند و ممکن است روی اینترنت ضعیف یا محدودکنندهٔ سرعت نتیجهٔ معکوس بدهند. مقدار پیش‌فرض ۴ برای شروع مناسب است. سرعت نهایی همچنین به CDN، محدودیت سرویس و کیفیت اینترنت بستگی دارد.

## اعلان‌ها

- اعلان پیشرفت برای اجرای قانونی دانلود پس‌زمینه (Foreground Service) لازم است و هنگام دانلود فعال نمایش داده می‌شود.
- اعلان پایان و خطا از تنظیمات برنامه قابل خاموش‌کردن است.
- در اندروید ۱۳+ مجوز `POST_NOTIFICATIONS` لازم است. درخواست فقط یک‌بار خودکار انجام می‌شود.
- اگر اعلان دیده نمی‌شود، از **تنظیمات آریا → بخش اعلان‌ها → باز کردن تنظیمات اعلان سیستم** هم اعلان کلی برنامه و هم کانال «پایان دانلود» را بررسی کنید.
- لمس اعلان پایان، فایل ذخیره‌شده را با برنامهٔ مناسب باز می‌کند.

## مدیریت دانلود

- توقف/ادامهٔ تکی و گروهی، تلاش مجدد خودکار و حالت فقط Wi-Fi
- حفظ صف پس از بسته‌شدن برنامه و ادامهٔ فایل‌های مستقیم از دادهٔ قبلی
- انتخاب چندتایی، جست‌وجو، فیلتر وضعیت، جزئیات، تغییر نام و حذف با/بدون فایل
- افزودن چند لینک از متن یا فایل متنی و الگوهایی مانند `image{01-20}.jpg`
- ذخیره در `Download/AriaDownloader/` با MediaStore در اندروید ۱۰+
- حداقل اندروید ۷ (API 24)، هدف اندروید ۱۳ (API 33)، معماری `arm64-v8a`

## کوکی‌ها

برای محتوای عمومی کوکی لازم نیست. اگر سرویس برای محتوای مجاز حساب شما ورود بخواهد:

1. از مرورگر خودتان خروجی Netscape با نام `cookies.txt` بگیرید.
2. در تنظیمات آریا، «وارد کردن cookies.txt» را انتخاب کنید.
3. فایل فقط در حافظهٔ خصوصی برنامه ذخیره می‌شود و هر زمان قابل حذف است.

کوکی معادل کلید نشست حساب است؛ آن را در Git یا برای دیگران ارسال نکنید.

## ساخت از سورس

پیش‌نیازها: JDK 17، Android SDK Platform 33 و Python 3.13 روی سیستم بیلد.

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug
```

خروجی Debug در `app/build/outputs/apk/debug/` ساخته می‌شود. فایل‌های APK، کش بیلد و `local.properties` در Git نگهداری نمی‌شوند.

### امضای Release (اختیاری)

```bash
cp keystore.properties.example keystore.properties
# مسیر و رمزهای واقعی را فقط در فایل محلی وارد کنید
./gradlew assembleRelease
```

`keystore.properties` و فایل‌های `*.jks` / `*.keystore` در `.gitignore` هستند. بدون این فایل، Release به‌صورت unsigned ساخته می‌شود و سورس به هیچ رمز ثابتی نیاز ندارد.

## تست

```bash
# تست موتور پایتون با همان فایل بسته‌بندی‌شده در APK
python3 -m pip install 'yt-dlp==2026.10.21' 'certifi==2026.10.23'
PYTHONPATH=app/src/main/python python3 -m unittest discover -s app/src/test/python -v

# تست‌های Kotlin/JVM/Robolectric و Lint
./gradlew testDebugUnitTest lintDebug
```

تست‌های رگرسیون Aparat و Pornhub از ساختار واقعی فرمت‌های extractor استفاده می‌کنند و نیازی به دانلود محتوای واقعی ندارند. تست شبکهٔ زنده و اجرای روی گوشی فیزیکی باید جداگانه انجام شود.

فقط محتوایی دانلود کنید که مالک آن هستید یا مجوز دانلودش را دارید و شرایط هر سرویس و قوانین محلی را رعایت کنید. محتوای محافظت‌شدهٔ DRM پشتیبانی نمی‌شود.
